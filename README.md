# ☄️ 별똥별 피하기 (Meteor Dodge)

HTML 파일 하나로 만든 웹 게임입니다. AI 코딩 도구(Claude Code)로 게임을 만들고, Git과 GitHub에 올린 뒤 GitHub Pages로 배포했습니다.

**🎮 플레이하기:** https://bluerose219.github.io/meteor-dodge/

---

## 게임 소개

- 떨어지는 운석 ☄️을 피하면 **+1점**
- 노란 별 ⭐을 먹으면 **+10점**
- 목숨은 **3개**이고, 부딪히면 화면이 흔들리고 잠깐 무적이 됩니다.
- 시간이 지날수록 운석이 더 빠르고 더 자주 떨어집니다.
- 최고 기록은 브라우저에 저장됩니다.

### 조작법

| 동작 | 키 |
| --- | --- |
| 좌우 이동 | `←` `→` 또는 `A` `D` (마우스·터치 드래그도 가능) |
| 일시정지 | `P` |
| 시작 / 다시 하기 | `Space`, `Enter` 또는 버튼 클릭 |

## 수업 내용 정리

### 1. HTML 하나로 웹 게임 만들기

`index.html` 파일 하나에 세 가지가 모두 들어 있습니다.

- **HTML**: 화면 구조. 게임 화면(`<canvas>`), 점수판, 시작 화면을 만듭니다.
- **CSS**: 꾸미기. 색상, 버튼 모양, 화면 가운데 정렬을 맡습니다.
- **JavaScript**: 게임 동작. 움직임, 충돌, 점수를 처리합니다.

게임 동작에 쓰인 핵심 개념은 다음과 같습니다.

- **Canvas**: `<canvas>`에 도형과 그림을 직접 그려 게임 화면을 만듭니다.
- **게임 루프**: `requestAnimationFrame`으로 1초에 약 60번씩 *업데이트(위치 계산) → 그리기*를 반복합니다.
- **충돌 판정**: 두 물체의 중심 사이 거리(`Math.hypot`)가 두 반지름의 합보다 작으면 부딪힌 것으로 봅니다.
- **입력 처리**: `keydown`/`keyup`(키보드)과 `pointermove`(마우스·터치) 이벤트로 플레이어를 움직입니다.
- **난이도 상승**: 경과 시간(`time`)에 따라 운석 속도와 생성 간격이 달라집니다.
- **localStorage**: 브라우저에 최고 기록을 저장합니다.

### 2. Git과 GitHub

- **Git**: 내 컴퓨터에서 파일의 변경 기록(버전)을 관리하는 도구입니다.
- **GitHub**: Git 저장소를 인터넷에 올려 보관하고 공유하는 서비스입니다.

이번에 사용한 명령어는 다음과 같습니다.

```bash
git init -b main          # 현재 폴더를 Git 저장소로 만들기 (기본 브랜치: main)
git add index.html        # 커밋할 파일 선택(스테이징)
git commit -m "메시지"     # 변경 내용을 하나의 버전으로 저장
gh repo create meteor-dodge --public --source . --push
                          # GitHub에 공개 저장소를 만들고 바로 업로드
```

### 3. GitHub Pages로 배포하기

- **GitHub Pages**는 저장소에 있는 HTML 파일을 무료 웹사이트로 띄워 주는 기능입니다.
- 무료 계정에서는 **public(공개) 저장소**만 사용할 수 있습니다.
- 설정 방법: 저장소의 **Settings → Pages → Branch: `main` / `(root)`**를 선택하고 저장합니다. 이번에는 명령어로 설정했습니다.
- 주소 형식: `https://<아이디>.github.io/<저장소이름>/`
- 첫 화면 파일 이름이 `index.html`이어야 주소만으로 바로 열립니다.

### 4. 수정 후 다시 배포하는 방법

```bash
git add .
git commit -m "수정 내용"
git push
```

push하고 1~2분 정도 지나면 사이트에 자동으로 반영됩니다.

## 사용한 프롬프트

Claude Code에 실제로 입력한 프롬프트와 그 결과입니다.

| 순서 | 프롬프트 | 결과 |
| --- | --- | --- |
| 1 | `아무 웹 게임을 html로 만들어줘` | `index.html` 하나로 된 "별똥별 피하기" 게임 생성 |
| 2 | `깃에 올리고 깃 페이지에 배포해줘` | Git 저장소를 만들고 커밋한 뒤, GitHub에 `meteor-dodge` 저장소를 만들어 push하고 GitHub Pages 배포 |
| 3 | `깃허브 찾아줘` | 브라우저로 GitHub 저장소 페이지 열기 |
| 4 | `readme 수업 내용 정리해서 올려줘 사용한 프롬프트도 같이 정리해줘` | 이 `README.md`를 작성해 GitHub에 업로드 |

### 프롬프트 작성 팁

- **짧게 말해도 됩니다.** "아무 웹 게임"처럼 넓게 요청하면 AI가 알아서 정해서 만들어 줍니다.
- **원하는 것이 있으면 구체적으로 말하세요.** 예: `점프해서 장애물을 피하는 게임을 만들어줘. 스페이스바로 점프하고, 점수가 화면 위에 보이게 해줘`
- **고칠 점은 이어서 요청하세요.** 예: `운석 속도를 조금 느리게 해줘`, `배경 음악을 넣어줘`, `모바일에서도 버튼으로 움직이게 해줘`
